# 🏆 Hackathon

<div align="center">

### 🚀 Bhartiya Antariksh Hackathon 2026

**GaganiX — AI-Driven Space Weather Radiation Forecasting System**

**Problem Statement:**  
*Forecasting Energetic Particle Radiation Environment for ISRO's Geostationary Satellites*

</div>

GaganiX was developed collaboratively by a **4-member team** to process satellite radiation and solar-wind observations and develop AI-based multi-horizon energetic particle radiation forecasting for geostationary satellite environments.
